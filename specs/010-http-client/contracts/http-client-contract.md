# Contract: HTTP-клиент BSL

**Feature**: [spec.md](../spec.md) | **Plan**: [plan.md](../plan.md) | **Data model**: [data-model.md](../data-model.md)

Контракт фиксирует пользовательскую поверхность BSL и внутренний контракт транспорта.
Имена и семантика — из `reference/OneScript/src/OneScript.StandardLibrary/Http/`
(`HttpConnectionContext.cs`, `HttpRequestContext.cs`, `HttpResponseContext.cs`).

## 1. Конструкторы

| BSL (RU) | BSL (EN) | Аргументы | Результат / ошибки |
|---|---|---|---|
| `Новый HTTPСоединение(Сервер, Порт, Пользователь, Пароль, Прокси, Таймаут, SSL, ИспользоватьАутентификациюОС)` | `New HTTPConnection(...)` | только `Сервер` обязателен; остальные опциональны | объект соединения; ошибки — см. §6 |
| `Новый HTTPЗапрос` | `New HTTPRequest` | — | пустой запрос (`АдресРесурса = ""`) |
| `Новый HTTPЗапрос(АдресРесурса, Заголовки)` | `New HTTPRequest(...)` | `АдресРесурса` — строка; `Заголовки` — `Соответствие` или `Неопределено` | запрос с адресом/заголовками; не-`Соответствие` → ошибка типа |

`Новый HTTPОтвет` недоступен (тип не регистрируется как конструктор), как и в эталоне.

### Позиции аргументов соединения

| № | Имя | Тип | По умолчанию | Примечание |
|---|---|---|---|---|
| 1 | `Сервер` / `Host` | строка | — | `example.com`, `http://example.com`, `https://example.com/base/` |
| 2 | `Порт` / `Port` | число | `0` | `0` — порт из URL/схемы |
| 3 | `Пользователь` / `User` | строка | `""` | basic-auth |
| 4 | `Пароль` / `Password` | строка | `""` | basic-auth |
| 5 | `Прокси` / `Proxy` | объект | `Неопределено` | принимается и игнорируется |
| 6 | `Таймаут` / `Timeout` | число | `0` | секунды; `0` — бесконечно |
| 7 | `SSL` / `SSL` | объект | `Неопределено` | не-`Неопределено` → ошибка |
| 8 | `ИспользоватьАутентификациюОС` / `UseOSAuthentication` | булево | `Ложь` | свойство без эффекта в браузере |

## 2. `HTTPЗапрос` / `HTTPRequest`

| Член | Вид | Аргументы | Поведение |
|---|---|---|---|
| `АдресРесурса` / `ResourceAddress` | свойство | — | строка; чтение/запись |
| `Заголовки` / `Headers` | свойство | — | `Соответствие`; сеттер принимает только `Соответствие` |
| `УстановитьТелоИзСтроки` / `SetBodyFromString` | метод | `Данные`, `Кодировка?`, `ИспользоватьBOM?` | кодирует строку (UTF-8 по умолчанию, без BOM) |
| `ПолучитьТелоКакСтроку` / `GetBodyAsString` | метод | — | декодирует тело (UTF-8 c учётом BOM) или `Неопределено` |
| `УстановитьТелоИзДвоичныхДанных` / `SetBodyFromBinaryData` | метод | `ДвоичныеДанные` | сохраняет байты; неверный тип → ошибка |
| `ПолучитьТелоКакДвоичныеДанные` / `GetBodyAsBinaryData` | метод | — | `ДвоичныеДанные` или `Неопределено` |

Не реализованы (вызов → ошибка «Метод … не найден»): `УстановитьИмяФайлаТела`,
`ПолучитьИмяФайлаТела`, `ПолучитьТелоКакПоток` — в браузере нет доступа к файлам и
потокам (spec.md, Assumptions).

## 3. `HTTPСоединение` / `HTTPConnection`

| Метод | Аргументы | HTTP-метод | Возврат |
|---|---|---|---|
| `Получить` / `Get` | `Запрос`, `ИмяФайла?` | `GET` | `HTTPОтвет` |
| `ОтправитьДляОбработки` / `Post` | `Запрос`, `ИмяФайла?` | `POST` | `HTTPОтвет` |
| `Записать` / `Put` | `Запрос` | `PUT` | `HTTPОтвет` |
| `Удалить` / `Delete` | `Запрос` | `DELETE` | `HTTPОтвет` |
| `Изменить` / `Patch` | `Запрос` | `PATCH` | `HTTPОтвет` |
| `ПолучитьЗаголовки` / `Head` | `Запрос` | `HEAD` | `HTTPОтвет` |
| `ВызватьHTTPМетод` / `CallHTTPMethod` | `Метод`, `Запрос`, `ИмяФайла?` | как указано | `HTTPОтвет` |

`ИмяФайла` (имя файла для сохранения ответа) в браузере не поддерживается: непустое
значение → ошибка «запись ответа в файл не поддерживается». В Node-транспорте — тоже не
реализовано в этой итерации (spec.md, Assumptions).

| Свойство | Вид | Значение |
|---|---|---|
| `Сервер` / `Host` | чтение | хост из URL |
| `Порт` / `Port` | чтение | порт из URL или 80/443 |
| `Пользователь` / `User` | чтение | из конструктора |
| `Пароль` / `Password` | чтение | из конструктора |
| `Прокси` / `Proxy` | чтение | всегда `Неопределено` |
| `Таймаут` / `Timeout` | чтение | секунды |
| `РазрешитьАвтоматическоеПеренаправление` / `AllowAutoRedirect` | чтение/запись | `Истина` по умолчанию |
| `ИспользоватьАутентификациюОС` / `UseOSAuthentication` | чтение | из конструктора |

**Тело запроса**: отправляется для всех методов, кроме `GET`, `HEAD`, `CONNECT`
(семантика `ContentBodyAllowed` эталона). Пустой/незаданный `body` — запрос без тела.

**Basic-auth**: при непустых `Пользователь`/`Пароль` добавляется
`Authorization: Basic base64(UTF-8 "<user>:<password>")`.

**URL**: `new URL(Ресурс, БазаСоединения)`; `Ресурс = ""` → базовый URL.

## 4. `HTTPОтвет` / `HTTPResponse`

| Член | Вид | Аргументы | Поведение |
|---|---|---|---|
| `КодСостояния` / `StatusCode` | свойство | — | число |
| `Заголовки` / `Headers` | свойство | — | `Соответствие`; имена — в регистре сервера |
| `ПолучитьТелоКакСтроку` / `GetBodyAsString` | метод | `Кодировка?` | строка; `Неопределено`, если тела нет |
| `ПолучитьТелоКакДвоичныеДанные` / `GetBodyAsBinaryData` | метод | — | `ДвоичныеДанные`; `Неопределено`, если тела нет |
| `Закрыть` / `Close` | метод | — | освобождает тело; идемпотентно; после закрытия тело `Неопределено` |

Тело отсутствует для `204`, `304`, `HEAD` и `Content-Length: 0`.
Кодировка строки: `charset` из `Content-Type`, затем `utf-8`.
При распаковке gzip: `Content-Encoding` удаляется, `Content-Length` = фактический размер.

## 5. Контракт транспорта (внутренний)

```ts
interface HttpRequestData {
  method: string;
  url: string;
  headers: readonly [string, string][];
  body: Uint8Array | null;
  timeoutMs: number;      // 0 = без таймаута
  allowRedirect: boolean;
}

interface HttpResponseData {
  status: number;
  headers: [string, string][];
  body: Uint8Array;       // допускается пустой
}

type HttpTransport = (request: HttpRequestData) => HttpResponseData;
```

Обязанности транспорта:

1. Выполнить запрос синхронно и вернуть ответ для **любого** статуса (3xx/4xx/5xx — не ошибка).
2. Бросить `Error` при сетевой ошибке, CORS, таймауте, TLS — с текстовой причиной.
3. Не добавлять и не удалять заголовки, кроме служебных, которыми управляет платформа
   (`Content-Length`, `Host`, `Connection`, `Transfer-Encoding`, `User-Agent`).
4. Не декодировать тело в строку — возвращать байты; кодировку выбирает ядро.

Регистрация: `createGlobalContext(transport?)`; браузер — `src/browser/http-transport.ts`,
Node — `src/node/http-transport.ts`, тесты — фейковая функция.

## 6. Ошибки

| Условие | Когда | Текст (смысл) |
|---|---|---|
| Нет транспорта | создание `HTTPСоединение` | «HTTP-запросы недоступны в этом окружении» |
| Схема не http/https | создание | «Недопустимая схема адреса: <схема>» |
| Порт вне 1…65535 | создание | «Недопустимый порт: <значение>» |
| SSL задан | создание | «Защищенное соединение по произвольным сертификатам не поддерживается…» |
| `Заголовки` не `Соответствие` | создание запроса / присваивание | «Неверный тип аргумента: Заголовки должны быть Соответствием» |
| Тело не `ДвоичныеДанные` | `УстановитьТелоИзДвоичныхДанных` | «Неверный тип аргумента» |
| Сеть/CORS/таймаут | запрос | «Не удалось выполнить HTTP-запрос <METHOD> <URL>: <причина>» |
| Неизвестный метод/свойство | вызов | «Метод/Свойство '<имя>' не найден(о) у типа <тип>» |

## 7. Примеры BSL

Получение JSON:

```bsl
Соединение = Новый HTTPСоединение("https://api.example.com");
Запрос = Новый HTTPЗапрос("/api/users");
Ответ = Соединение.Получить(Запрос);
Если Ответ.КодСостояния = 200 Тогда
    Данные = ПрочитатьJSON(Ответ.ПолучитьТелоКакСтроку());
    Сообщить(Данные.Имя);
КонецЕсли;
```

Отправка JSON:

```bsl
Запрос = Новый HTTPЗапрос("/api/orders");
Запрос.Заголовки.Вставить("Content-Type", "application/json");
Запрос.УстановитьТелоИзСтроки("{""id"": 42}");
Ответ = Соединение.ОтправитьДляОбработки(Запрос);
```

Заголовки и код ошибки без исключения:

```bsl
Ответ = Соединение.Получить(Новый HTTPЗапрос("/missing"));
Если Ответ.КодСостояния = 404 Тогда
    Сообщить("Не найдено: " + Ответ.ПолучитьТелоКакСтроку());
КонецЕсли;
```
