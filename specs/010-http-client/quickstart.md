# Quickstart: проверка HTTP-клиента BSL

**Feature**: [spec.md](spec.md) | **Plan**: [plan.md](plan.md) | **Contract**: [contracts/http-client-contract.md](contracts/http-client-contract.md)

## Prerequisites

- Node.js >= 20 (в DSH — системный node из nvm, см. `AGENTS.md` §6).
- Установленные зависимости: `pnpm install`.
- Транспорт в тестах — фейковый (без сети); браузерный транспорт проверяется в `happy-dom`
  через `fetch.interceptor.beforeSyncRequest`.
- Для ручной проверки Node-транспорта нужен локальный эхо-сервер (пример ниже).

## 1. Автоматические проверки

```bash
export PATH="$HOME/.nvm/versions/node/v24.22.0/bin:$PATH"
pnpm typecheck
pnpm test            # ожидается: все файлы/тесты зелёные, включая tests/http*.test.ts
pnpm build:browser   # dist/onescript.js собирается без Node-зависимостей
```

Ожидаемые артефакты и результаты:

| Проверка | Ожидание |
|---|---|
| `pnpm typecheck` | без ошибок |
| `pnpm test` | `tests/http.test.ts` и `tests/http-browser.test.ts` зелёные; прежние тесты не сломаны |
| `pnpm build:browser` | IIFE-бандл содержит `HTTPСоединение`, `HTTPЗапрос`, `HTTPОтвет` |
| `grep -c "node:child_process" dist/onescript.js` | `0` — Node-транспорт не попал в браузерный бандл |

## 2. Ручная проверка в браузере (основная среда)

1. Собрать бандл: `pnpm build:browser`.
2. Поднять бэкенд, который отдаёт JSON и разрешает CORS:

   ```bash
   node -e "require('http').createServer((q,s)=>{s.setHeader('Content-Type','application/json; charset=utf-8');s.setHeader('Access-Control-Allow-Origin','*');s.end(JSON.stringify({name:'Никита',age:38}))}).listen(3000)"
   ```

3. Открыть страницу с бандлом и кодом:

   ```html
   <script src="/dist/onescript.js"></script>
   <one-script>
     Соединение = Новый HTTPСоединение("http://127.0.0.1:3000");
     Ответ = Соединение.Получить(Новый HTTPЗапрос("/api/me"));
     Сообщить(Ответ.КодСостояния);
     Данные = ПрочитатьJSON(Ответ.ПолучитьТелоКакСтроку());
     Сообщить(Данные.Имя);
   </one-script>
   ```

4. В консоли страницы: `200`, затем `Никита`.

Ограничения браузера, которые нужно помнить: запрос синхронный (страница ждёт ответ),
кросс-доменный бэкенд обязан разрешать CORS, запрещённые браузером заголовки не уходят.

## 3. Ручная проверка из CLI (вспомогательная среда)

```bash
node -e "require('http').createServer((q,s)=>{s.setHeader('Content-Type','text/plain');s.end('ok')}).listen(3100)" &
node dist/cli.mjs script.os
```

`script.os`:

```bsl
Соединение = Новый HTTPСоединение("http://127.0.0.1:3100");
Ответ = Соединение.Получить(Новый HTTPЗапрос("/"));
Сообщить(Ответ.КодСостояния);                 // 200
Сообщить(Ответ.ПолучитьТелоКакСтроку());      // ok
```

Node-транспорт запускает дочерний процесс `node -e` на каждый запрос — это медленно
(~100 мс), но детерминированно и не требует зависимостей.

## 4. Сценарии приёмки (соответствуют spec.md)

| # | Сценарий | Как проверить | Ожидание |
|---|---|---|---|
| 1 | GET JSON | `tests/http.test.ts`: фейковый транспорт отдаёт `200` + JSON | статус 200, `ПрочитатьJSON` разбирает строку |
| 2 | Разрешение ресурса | фейковый транспорт записывает `url` для `base/` + `users` и `/users` | `/base/users` и `/users` |
| 3 | Кодировка ответа | тело в windows-1251 + `charset=windows-1251` | строка декодирована верно |
| 4 | 404 — не исключение | фейковый ответ 404 с телом | `КодСостояния = 404`, тело доступно |
| 5 | Тело отсутствует | `204`/`HEAD` | `ПолучитьТелоКакСтроку() = Неопределено` |
| 6 | POST строкой | эхо-сервер/фейк | метод `POST`, тело UTF-8 байт-в-байт |
| 7 | PUT двоичными | фейк | метод `PUT`, те же байты |
| 8 | Произвольный метод | `ВызватьHTTPМетод("OPTIONS", …)` | метод `OPTIONS` |
| 9 | Basic-auth | фейк | `Authorization: Basic …` |
| 10 | Ошибки конфигурации | `ftp://`, неверный тип `Заголовки`, SSL | локализованные исключения |
| 11 | Браузерный транспорт | `tests/http-browser.test.ts` (happy-dom) | запрос ушёл, ответ прочитан, бинарные байты не искажены |
| 12 | Нет транспорта | `createGlobalContext()` без аргумента | создание соединения → исключение, остальная stdlib работает |

## 5. Откат/диагностика

- Если браузерный запрос падает — открыть DevTools → Network: видно ли CORS-preflight,
  какой статус, какие заголовки ушли.
- Если `ПолучитьТелоКакСтроку` возвращает `Неопределено` — проверить `КодСостояния`
  (`204`/`304`), `Content-Length: 0` и метод (`HEAD`).
- Если строка «кракозябры» — проверить `Content-Type: …; charset=…`; при отсутствии
  заголовка передать кодировку явно: `Ответ.ПолучитьТелоКакСтроку("windows-1251")`.
