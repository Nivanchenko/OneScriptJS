# Data Model: HTTP-клиент BSL

**Feature**: [spec.md](spec.md) | **Plan**: [plan.md](plan.md) | **Contracts**: [contracts/http-client-contract.md](contracts/http-client-contract.md)

## 1. Транспортный уровень (ядро ↔ платформа)

### 1.1 `HttpRequestData` — запрос, который исполняет платформа

| Поле | Тип | Инвариант |
|---|---|---|
| `method` | `string` | Непустой HTTP-метод в верхнем регистре (`GET`, `POST`, `OPTIONS`, …) |
| `url` | `string` | Абсолютный `http`/`https` URL, уже собранный ядром |
| `headers` | `readonly [string, string][]` | Имена и значения — строки; порядок сохраняется |
| `body` | `Uint8Array \| null` | `null`, если тела нет или метод `GET`/`HEAD`/`CONNECT` |
| `timeoutMs` | `number` | `0` — без таймаута; иначе миллисекунды (> 0) |
| `allowRedirect` | `boolean` | `false` — не следовать редиректам (где среда умеет) |

### 1.2 `HttpResponseData` — ответ платформы

| Поле | Тип | Инвариант |
|---|---|---|
| `status` | `number` | Код состояния (включая 3xx/4xx/5xx) |
| `headers` | `[string, string][]` | Заголовки в регистре сервера; дубликаты допустимы |
| `body` | `Uint8Array` | Может быть пустым; `null` не возвращается |

### 1.3 `HttpTransport`

```ts
type HttpTransport = (request: HttpRequestData) => HttpResponseData;
```

Синхронный: либо возвращает ответ, либо бросает `Error` с причиной. Сетевые ошибки
оборачивает вызывающая сторона (ядро), добавляя метод и URL.

## 2. BSL-объекты

### 2.1 `HTTPЗапрос` / `HTTPRequest` (`BslHttpRequest`)

| Поле | Тип | Начальное значение | Правило |
|---|---|---|---|
| `resourceAddress` / `АдресРесурса` | `string` | `""` | Читается/пишется; приводится `toStringValue` |
| `headers` / `Заголовки` | `BslMap` | пустое `Соответствие` | Сеттер принимает только `BslMap`, иначе исключение |
| `body` | `Uint8Array \| null` | `null` | Меняется только методами тела |

**Переходы тела**:

```text
null ──УстановитьТелоИзСтроки(строка, кодировка?, BOM?)──▶ байты UTF-8/кодировки
null ──УстановитьТелоИзДвоичныхДанных(ДвоичныеДанные)────▶ копия байтов
байты ──УстановитьТелоИзСтроки/ИзДвоичныхДанных─────────▶ новые байты (старые отбрасываются)
```

`ПолучитьТелоКакСтроку` декодирует текущие байты (UTF-8, с учётом BOM);
`ПолучитьТелоКакДвоичныеДанные` возвращает `ДвоичныеДанные` или `Неопределено`, если тела нет.

### 2.2 `HTTPСоединение` / `HTTPConnection` (`BslHttpConnection`)

| Поле | Тип | Изменяемость | Правило |
|---|---|---|---|
| `transport` | `HttpTransport` | — | Обязателен; без него конструктор бросает исключение |
| `host` | `string` | только чтение | Хост без схемы (`url.hostname`) |
| `port` | `number` | только чтение | Порт URL или 80/443 по схеме |
| `user`, `password` | `string` | только чтение | `""` по умолчанию |
| `proxy` | `undefined` | только чтение | Всегда `Неопределено` |
| `timeout` | `number` | только чтение | Секунды; `0` — бесконечно |
| `allowAutoRedirect` | `boolean` | чтение/запись | По умолчанию `Истина` |
| `useOSAuthentication` | `boolean` | только чтение | По умолчанию `Ложь`; в браузере без эффекта |
| `baseUrl` | `URL` | — | Схема + хост + порт + путь из `Сервер` |

**Валидация конструктора** (`args` позиционные, пропуски = `Неопределено`):

1. `Сервер` обязателен; без схемы добавляется `http://`.
2. Схема после нормализации — только `http:`/`https:`, иначе исключение.
3. `Порт`, если задан (`!= 0`), — целое 1…65535, иначе исключение.
4. `SSL` (аргумент 7), если не `Неопределено`, — исключение о неподдерживаемом SSL.
5. `Прокси` (аргумент 5) принимается и игнорируется.

**Сборка URL ресурса**:

```text
target = new URL(resource, baseUrl)   // resource "" → baseUrl
```

### 2.3 `HTTPОтвет` / `HTTPResponse` (`BslHttpResponse`)

| Поле | Тип | Правило |
|---|---|---|
| `status` / `КодСостояния` | `number` | Только чтение |
| `headers` / `Заголовки` | `BslMap` | Только чтение ссылки (сам map изменяем, как в эталоне) |
| `body` | `Uint8Array \| null` | `null` — тело отсутствует |
| `closed` | `boolean` | `Закрыть` → `true`, повторный вызов идемпотентен |

**Правило отсутствия тела**: `null`, если `status ∈ {204, 304}`, метод `HEAD` или
`Content-Length: 0`; иначе байты (возможно пустые).

**Нормализация gzip**: если в ответе есть `Content-Encoding` ≠ `identity` —
заголовок удаляется, `Content-Length` заменяется фактической длиной тела.

**Кодировка строки**: `charset` из `Content-Type` → `TextDecoder`; по умолчанию `utf-8`;
явный аргумент переопределяет.

## 3. Связи

```text
BSL-скрипт
  └─ HTTPСоединение ──(transport)──▶ платформа (XHR / child fetch)
        │  1..*
        ▼
     HTTPЗапрос ──(заголовки + тело)──▶ HttpRequestData
        │
        ▼
     HTTPОтвет ◀── HttpResponseData ──(status + headers + body)── платформа
```

## 4. Ошибки и их источники

| Ситуация | Источник | Сообщение (смысл) |
|---|---|---|
| Нет транспорта | конструктор соединения | HTTP-запросы недоступны в этом окружении |
| Схема не http/https | конструктор | недопустимая схема адреса |
| Порт вне 1…65535 | конструктор | недопустимый порт |
| SSL-объект передан | конструктор | произвольные сертификаты не поддерживаются |
| `Заголовки` не `Соответствие` | конструктор/сеттер запроса | неверный тип аргумента |
| Сеть/CORS/таймаут | транспорт → ядро | `Не удалось выполнить HTTP-запрос <METHOD> <URL>: <причина>` |
| Метод/свойство неизвестны | `BslObject` | `Метод 'X' не найден у типа HTTPЗапрос` |
