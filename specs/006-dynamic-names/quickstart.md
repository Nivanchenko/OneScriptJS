# Quickstart: проверка разрешения имён в `Выполнить`/`Вычислить`

**Feature**: [006-dynamic-names](./spec.md) | **Plan**: [plan.md](./plan.md) | **Date**: 2026-11-23

## Prerequisites

- Node.js >= 20 (в DSH — системный node из nvm: `export PATH="$HOME/.nvm/versions/node/v24.22.0/bin:$PATH"`).
- Установленные зависимости: `pnpm install` (или `node "$DSH_PNPM" install` в DSH).
- `reference/OneScript/` на месте (клон апстрима; не коммитится).

## 1. Юнит-тесты фичи (Node, Vitest)

```bash
pnpm vitest run tests/eval-dynamic-names.test.ts
```

Ожидается: все сценарии зелёные, включая перенесённый эталонный
`ТестДолжен_ПроверитьВызовыВыполнитьСПопытками` с результатом `0134567+`.

Проверка контракта [contracts/dynamic-name-resolution.md](./contracts/dynamic-name-resolution.md):

- `Выполнить "Рез = Рез + 3"` при `Рез = 1` → `4`;
- `Выполнить "Т = 5"`, затем `Выполнить "Сообщить(Т)"` → ошибка `Неизвестный символ: Т`;
- `Попытка Выполнить "Сообщить(""до""); Х = Х + 1;"` → «до» не печатается, ошибка ловится,
  `ОписаниеОшибки()` содержит имя;
- `Сообщить(Строка(НетТакой))` в статическом коде → `Неопределено` (FR-008).

## 2. Браузерная приёмка (конституция V)

```bash
pnpm vitest run tests/browser-script-tag.test.ts
```

Ожидается: script-блок с `Попытка Выполнить "Х = Х + 1"; Исключение … КонецПопытки;`
пишет в `console.log` текст «Неизвестный символ: Х» и страница не падает.

Ручная проверка (опционально): `pnpm build:browser && pnpm dev`, открыть
`examples/sandbox.html`, ввести `Сообщить(НетТакойПеременной);` и нажать «Выполнить» —
в журнале ошибка «Неизвестный символ: НетТакойПеременной»; ввести
`А = 1; Сообщить(А + 1);` — выполняется без ошибок.

## 3. Эталонный корпус

```bash
pnpm build:node   # dist/node нужен scripts/run-reference-tests.mjs
node scripts/run-reference-tests.mjs
```

Ожидается: `eval.os` больше не падает на `ТестДолжен_ПроверитьВызовыВыполнитьСПопытками`;
остаются 3 падения вне scope спеки (`ОбъединитьПути`/файловый контекст, спека 004).
Итоговый счётчик reference-прогона должен совпасть с baseline до фичи минус один упавший
файл (если `eval.os` целиком зелёным не станет из-за этих 3 тестов — это ожидаемо,
SC-005).

## 4. Полный гейт

```bash
pnpm typecheck && pnpm test && pnpm build:browser
```

Ожидается: typecheck без ошибок, все Vitest-тесты зелёные (baseline — 861 тест/86 файлов,
плюс новые), браузерный бандл собирается.
