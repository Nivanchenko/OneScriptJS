# Quickstart: проверка директивы #Использовать

**Date**: 2026-11-11 | **Plan**: [plan.md](plan.md) | **Spec**: [spec.md](spec.md)

Руководство по ручной и автоматической проверке фичи после реализации. Детали поведения —
в [контракте](contracts/use-directive-contract.md), структуры — в
[data-model.md](data-model.md).

## Предусловия

- Node.js >= 20, зависимости установлены: `pnpm install`.
- В DSH-окружении — системный Node из nvm (см. `AGENTS.md` §6).
- Собранный браузерный бандл: `pnpm build:browser` (для сценария 5).
- Исходная точка — корень репозитория.

## 1. Модуль: экспортные методы и переменные (Node)

Создать в временном каталоге два файла:

```text
/tmp/os-mod/Модуль.os
    Перем Поле Экспорт;

    Функция Сложить(А, Б) Экспорт
        Возврат А + Б;
    КонецФункции

    Поле = 10;
    Сообщить("модуль загружен");

/tmp/os-mod/main.os
    #Использовать "Модуль.os"
    Сообщить(Модуль.Сложить(1, 2));
    Модуль.Поле = Модуль.Поле + 5;
    Сообщить(Модуль.Поле);
    #Использовать "Модуль.os"
```

Ожидаемо: `модуль загружен` один раз, затем `3` и `15`. Второй `#Использовать` ничего не
перезагружает.

```bash
pnpm build:cli
node dist/cli.mjs /tmp/os-mod/main.os
```

Автотест (после реализации): `pnpm test -- tests/modules.test.ts`.

## 2. Класс: конструктор и независимые экземпляры

```text
/tmp/os-class/Класс.os
    Перем Значение Экспорт;
    Перем Счётчик;

    Процедура ПриСозданииОбъекта(Обязательный, Необязательный = "по умолчанию")
        Значение = Обязательный + "/" + Необязательный;
        Счётчик = 0;
    КонецПроцедуры

    Функция Увеличить() Экспорт
        Счётчик = Счётчик + 1;
        Возврат Счётчик;
    КонецФункции

/tmp/os-class/main.os
    #Использовать "Класс.os"
    А = Новый Класс("раз");
    Б = Новый Класс("два", "три");
    Сообщить(А.Значение);
    Сообщить(Б.Значение);
    Сообщить(А.Увеличить());
    Сообщить(А.Увеличить());
    Сообщить(Б.Увеличить());
```

Ожидаемо: `раз/по умолчанию`, `два/три`, `1`, `2`, `1` (состояния независимы).
Автотест: `pnpm test -- tests/modules.test.ts`.

## 3. Кеш и цикл

```text
/tmp/os-cycle/A.os:  #Использовать "B.os"   + Перем Имя Экспорт; Имя = "A";
/tmp/os-cycle/B.os:  #Использовать "A.os"   + Перем Имя Экспорт; Имя = "B";
/tmp/os-cycle/main.os: #Использовать "A.os"
```

Ожидаемо: запуск завершается, тело A и B исполнено по одному разу; после импорта
`A.Имя` и `B.Имя` доступны. Если B обращается к `A.Имя` на верхнем уровне до завершения A —
ошибка `Модуль 'A' ещё загружается (циклический импорт)`, а не зависание.

Автотест: `pnpm test -- tests/modules.test.ts`.

## 4. Диагностика

| Проверка | Ожидаемо |
|---|---|
| `#Использовать "нет-такого.os"` | `Файл не найден: '<путь>' (директива #Использовать, строка N)` |
| Директива после кода | `Директива #Использовать должна быть расположена в начале модуля (строка N)` |
| `#Использовать "my-script.os"` | ошибка «не является допустимым идентификатором» |
| Два файла `a/Модуль.os` и `b/Модуль.os` | `Имя 'Модуль' уже занято (файл '<путь>')` |
| Вложенный файл с `Если (` без `КонецЕсли` | `Ошибка в импортируемом файле '<путь>': …` |
| `Новый Модуль` | ошибка «модуль не является классом» |
| `Класс.Метод` | ошибка «класс не является модулем» |
| `Новый Класс()` без обязательного аргумента | `Параметры конструктора: …` |
| `#Использовать asserts` | выполняется без ошибок и без загрузки файла |

Автотест: `pnpm test -- tests/modules.test.ts tests/preprocessor.test.ts`.

## 5. Браузер: загрузка по URL

1. Положить рядом с `examples/` файлы `Модуль.os` и страницу с:

   ```html
   <one-script>
       #Использовать "/examples/Модуль.os"
       Сообщить(Модуль.Сложить(2, 3));
   </one-script>
   ```

2. `pnpm dev` (или `pnpm demo`), открыть страницу в браузере.
3. Ожидаемо: в консоли `5`; относительный `#Использовать "Модуль.os"` (рядом со страницей)
   также работает. Для 404 — `console.error` с URL и статусом; страница не падает.

Автотест (happy-dom + заглушка `fetch`): `pnpm test -- tests/browser-modules.test.ts`.

## 6. Динамический сценарий с импортом

```text
/tmp/os-dyn/main.os
    Код = "#Использовать ""lib/Модуль.os""" + Символы.ПС + "Сообщить(Модуль.Поле);";
    ЗагрузитьСценарийИзСтроки(Код, "/tmp/os-dyn/dyn.os");
```

Ожидаемо: модуль загружается (или берётся из кеша) и печатает своё поле. Без второго
аргумента импорт резолвится от пути `main.os`. В браузере динамический импорт работает
только для файлов, уже предзагруженных страницей (runtime-`fetch` в синхронном движке нет).

Автотест: `pnpm test -- tests/modules-dynamic.test.ts`.

## 7. Обязательная проверка перед «готово»

```bash
pnpm typecheck
pnpm test
pnpm build
```

Ожидаемо: `tsc` без ошибок; все тестовые файлы и тесты зелёные (базовая линия до фичи —
43 файла / 300 тестов); сборка браузера и Node проходит. Приёмочно открыть
`examples/hello.html` на dev-сервере — три строки в консоли не изменились.
