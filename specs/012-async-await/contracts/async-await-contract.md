# Contract: Асинхронные методы (`Асинх`/`Ждать`, `Обещание`)

**Feature**: [spec.md](../spec.md) | **Plan**: [plan.md](../plan.md) | **Data model**: [data-model.md](../data-model.md)

## 1. Синтаксис BSL

```bsl
Асинх Функция Загрузить(Знач Адрес) Экспорт
    Приостановить(100);
    Возврат "данные: " + Адрес;
КонецФункции

Асинх Процедура Обновить() Экспорт
    Приостановить(10);
КонецПроцедуры

// Тело модуля или async-метод:
Результат = Ждать Загрузить("/api");
Ждать Обновить();              // оператор-выражение
Обещание = Загрузить("/api");
Значение = Ждать Обещание;     // повторное ожидание допустимо
Значение2 = Ждать 42;          // не-Обещание возвращается как есть
```

| Элемент | Правило |
|---|---|
| `Асинх`/`Async` | только непосредственно перед `Процедура`/`Функция`; контекстное слово |
| `Ждать`/`Await` | унарный префикс; операнд — постфиксное выражение; контекстное слово |
| Приоритет | `Ждать Вызов().Поле` = `Ждать (Вызов().Поле)`; бинарные операторы применяются после |
| Где допустим `Ждать` | в async-методе и в исполняемом теле модуля (расширение); в синхронном методе — ошибка |
| Где `Ждать`/`Асинх` — идентификаторы | вне async-контекста и в позициях имён: `Перем Ждать;`, `Ждать = 5;`, `Процедура Ждать()`, `Объект.Ждать`, `А = Ждать();` |
| Параметры async-метода | передаются по значению; `Знач` необязателен |

## 2. Семантика `Обещание`

| Операция | Результат |
|---|---|
| вызов `Асинх Функции` | `Обещание`, исполнение начато сразу; ожидание → значение `Возврат` |
| вызов `Асинх Процедуры` | `Обещание`, исполнение начато сразу; ожидание → `Неопределено` |
| `Ждать` fulfilled | кэшированное значение |
| `Ждать` rejected | бросает исходную ошибку (ловится `Попыткой`) |
| `Ждать` pending | приостанавливает текущий логический поток до settle |
| `Ждать` не-`Обещания` | возвращает значение как есть |
| повторное `Ждать` | из кэша (значение или та же ошибка) |
| ошибка до первой приостановки | не бросается вызывающему; сохраняется в `Обещании` |
| необработанная ошибка | `console.error`/stderr, сценарий продолжается |
| `Новый Обещание` | ошибка «Тип не найден» |
| методы/свойства `Обещания` | нет; любой доступ — ошибка |
| `ТипЗнч(Обещание)` | `Обещание` |
| `Строка(Обещание)` | `"Обещание"` |

## 3. Контракт рантайма

```ts
type PromiseState = 'pending' | 'fulfilled' | 'rejected';

class BslPromise implements BslObject {
  readonly typeName = 'Обещание';
  readonly completion: Promise<void>;          // never rejects
  state: PromiseState;
  await(): MaybePromise<Value>;                // pending → Promise; rejected → throw
  resolve(value: Value): void;                 // однократно
  reject(error: unknown): void;                // однократно
}

interface RuntimeEnvironment {
  // ...существующие поля (call/construct/events/flushAsync)
  trackAsync?(tracker: { completion: Promise<void> }): void;
  reportUnhandledError?(error: unknown): void;
}
```

**Инварианты**: settle однократен; `await()` кэширует; несколько ожидающих просыпаются вместе;
`completion` не отклоняется; unhandled-уведомление не более одного раза и только если `Ждать`
не было; `flushAsync` ждёт задания **и** незавершённые `Обещания`; при отсутствии работы
остаётся синхронным.

## 4. Контракт хостов

| Хост | Поведение |
|---|---|
| `<one-script>` | дожидается `run()` (включая async-тело и detached `Обещания`), затем binding; необработанные ошибки → `console.error` |
| CLI | `await run(...)`; необработанные ошибки → stderr; код возврата не меняется из-за detached-ошибки |
| `run`/`runScript` | `undefined` для полностью синхронного скрипта; Promise при async-исполнении |
| `ВызватьСобытие`/DOM-обработчики | async-обработчик запускается, но не ожидается; ошибка → хук хоста |

## 5. Диагностика

| Ситуация | Сообщение |
|---|---|
| `Ждать` в синхронном методе | «Ждать допустим только в асинхронном методе или теле модуля» |
| `Ждать` без операнда | «Ожидается выражение после Ждать» |
| `Ждать Ждать X` | «Нельзя ожидать результат ожидания» |
| `Асинх` без метода | «Ожидается Процедура или Функция после Асинх» |
| `Асинх ПриСозданииОбъекта` | «Асинхронный конструктор не поддерживается» |

Все сообщения — с позицией (строка/колонка), русские и английские алиасы ключевых слов.
