# Quickstart: проверка `Асинх`/`Ждать`

**Feature**: [spec.md](spec.md) | **Plan**: [plan.md](plan.md) | **Contract**: [contracts/async-await-contract.md](contracts/async-await-contract.md)

## Prerequisites

- Node.js >= 20 (в DSH — системный node из nvm, см. `AGENTS.md` §6).
- `pnpm install`; браузерные проверки — happy-dom; ручная — `examples/async.html`.

| `pnpm test` | 474 прежних теста + новые `parser-async`, `async-await`, `browser-async` зелёные |
| `pnpm build` | браузерный/Node/CLI бандлы собираются |

## 2. Ключевые сценарии

### 2.1 Async-функция + top-level `Ждать`

```bsl
Асинх Функция Считать(Знач Начало, Знач Конец) Экспорт
    Приостановить(50);
    Сумма = 0;
    Для Сч = Начало По Конец Цикл
        Сумма = Сумма + Сч;
    КонецЦикла;
    Возврат Сумма;
КонецФункции

Сообщить("до");
Результат = Ждать Считать(1, 100);
Сообщить(Результат);   // 5050
```

Ожидание: «до» — сразу; `5050` — после паузы; страница/хост не блокируются.

### 2.2 Ошибка ловится в точке `Ждать`

```bsl
Асинх Функция Упасть() Экспорт
    Приостановить(10);
    ВызватьИсключение "ошибка в async";
КонецФункции

Попытка
    Ждать Упасть();
Исключение
    Сообщить(ОписаниеОшибки());   // ошибка в async
КонецПопытки;
```

### 2.3 Async-процедура и повторное ожидание

```bsl
Асинх Процедура Обновить() Экспорт
    Приостановить(10);
КонецПроцедуры

Обещание = Обновить();
Ждать Обещание;              // Неопределено
Ждать Обещание;              // повторно — без ошибки
Ждать 42;                    // не-Обещание → 42
```

### 2.4 Контекстные идентификаторы (совместимость)

```bsl
Перем Ждать;
Процедура Ждать() Экспорт
КонецПроцедуры

Ждать = 5;
Ждать();
```

Ожидание: скрипт исполняется как раньше; `Асинх`/`Ждать` — обычные имена вне async-контекста.

## 3. Ручная проверка в браузере

1. `pnpm build:browser && pnpm dev`, открыть `examples/async.html`.
2. В консоли: маркер до результата, затем результат async-функции.
3. Нативный счётчик страницы продолжает тикать во время ожидания.
4. `examples/hello.html` — прежний приёмочный сценарий не сломан.
5. Async-процедура без ожидания с ошибкой: сценарий доходит до конца, ошибка видна в
   `console.error` один раз.

## 4. Проверка CLI

pnpm build
