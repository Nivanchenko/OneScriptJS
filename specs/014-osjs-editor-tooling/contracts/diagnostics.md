# Contract: диагностика `.osjs`

Правила первой версии: синтаксис (лексер, препроцессор, парсер) + **консервативные**
семантические проверки. Стилевых правил нет (FR-006). Сообщения — на русском, `source:
'osjs'`, стабильные `code`.

## Таблица правил

| Код | Severity | Условие | Диапазон |
|---|---|---|---|
| `OSJS1001` | Error | незакрытый строковый литерал / литерал даты; неожиданный символ | от начала проблемной лексемы до конца строки (или до конца текста) |
| `OSJS1002` | Error | ошибка директивы: `#Использовать` после кода, незакрытая/пустая строка пути | лексема директивы |
| `OSJS2001` | Error | ошибка разбора: неожиданный токен, ожидается ключевое слово/идентификатор/оператор/`;` | токен, на котором парсер остановился |
| `OSJS3001` | Warning | вызов неизвестной глобальной функции/имени в позиции вызова | имя вызываемого |
| `OSJS3002` | Warning | неверное число аргументов у известной функции/метода | имя вызываемого |
| `OSJS3003` | Warning | неизвестный тип в `Новый <Тип>` | имя типа |

Стилевых кодов (длина строки, неиспользуемые переменные и т.п.) нет — они прямо
исключены спекой.

## Условия и подавления

### Синтаксис (OSJS1001–2001)
- Собираются толерантным конвейером: несколько ошибок за один проход; после ошибки анализ
  продолжается.
- `OSJS2001` повторяет формулировку движка (`Ошибка разбора: …`), но без префикса и с
  диапазоном; текст стабилен, чтобы тесты не были хрупкими (проверяется код/позиция).
- Ошибки разбора не дублируются: одна и та же позиция с одним кодом — один раз.

### Семантика (OSJS3001–3003)
Проверки выполняются, только если **нет ошибок разбора** (частичный AST не годится для
выводов). Дополнительно:

- `knownGlobals` = функции/типы/перечисления/глобалы из каталога + имена методов
  модуля + `Перем` модуля + локальные имена метода (параметры, `Перем`, переменные
  присваиваний/циклов). Имена регистронезависимы.
- `OSJS3001`: только `CallExpression` с `Identifier` в позиции callee. Если имя нашли
  среди локальных символов (но это переменная, а не метод) — **не сообщаем** (консервативно:
  возможны динамические сценарии). Имена импортированных модулей считаются известными.
- `OSJS3002`: прямой вызов функции из каталога или метода текущего модуля. `required` —
  параметры без значения по умолчанию/`?`; `max` — все параметры (variadic → без предела).
  Слишком мало/слишком много аргументов — Warning. Пропущенные аргументы (`f(,1)`) считаются
  `Undefined`-аргументами (как в парсере).
- `OSJS3003`: только `NewObjectExpression` (форма `Новый Тип`) и **только если в файле нет
  ни одной директивы `#Использовать`** — иначе класс мог быть импортирован. Форма
  `Новый("Имя", …)` — динамическая, не проверяется.
- Подавление при `Выполнить`/`Вычислить`: статический анализ не видит динамических имён;
  если файл их использует, семантические проверки **не отключаются целиком** (это слишком
  грубо), но `OSJS3001` для имён, которые могли быть созданы динамически, не выдаётся —
  эвристика: не проверять вызовы, если имя не встречается как объявление/известный символ;
  см. ниже. Чтобы не ломать реальные скрипты, severity — Warning, не Error.

> `shortcut: эвристики семантических проверок консервативны; при жалобах на ложные
> срабатывания уточнять правила, а не отключать проверки.`

## Сообщения (шаблоны)

- `OSJS3001`: `Неизвестная функция «<Имя>».` (для типа/перечисления — `Неизвестный тип
  «<Имя>».`)
- `OSJS3002`: `Функция «<Имя>» ожидает не менее <N> аргументов.` /
  `Функция «<Имя>» ожидает не более <M> аргументов.`
- `OSJS3003`: `Неизвестный тип «<Имя>» в «Новый».`
- `OSJS1001/1002/2001`: текст из соответствующей ошибки движка, нормализованный под
  диапазон.

## Примеры (якоря для тестов)

```bsl
// 3 ошибки в одном файле: лексер + парсер + парсер (точные коды фиксирует тест)
Процедура Тест()
  А = 1 +;               // OSJS2001: ожидается выражение
  Б = 2 3;               // OSJS2001: ожидается ';'
  В = "незакрытая;       // OSJS1001: незакрытый строковый литерал
КонецПроцедуры
```

```bsl
// семантика (Warning)
НесуществующаяФункция(1);      // OSJS3001
СтрРазделить("а");             // OSJS3002 — ожидается 2 аргумента
Х = Новый НесуществующийТип;   // OSJS3003
```

## Пределы

- Не более 200 диагностик на документ (сортировка по позиции, лишние отбрасываются).
- Дедупликация по `(code, range.start)`.
- На документ с чужим `languageId` — пустой набор.
- При `didClose` — публикация пустого набора для uri.
