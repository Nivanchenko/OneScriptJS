# Contract: операторы событий BSL

**Date**: 2026-11-11 | **Plan**: [plan.md](../plan.md) | **Spec**: [spec.md](../spec.md)

Контракт описывает пользовательскую поверхность: что принимает движок и что наблюдает
скрипт. Совместимость с эталоном — `LanguageDef.cs` (`Token.AddHandler`,
`Token.RemoveHandler`), `DefaultBslParser.BuildEventHandlerOperation`,
`DefaultEventProcessor`, `ThisAwareScriptedObjectBase`.

## 1. Грамматика (расширение операторов)

```text
handler-statement := add-handler | remove-handler

add-handler    := ADD-HANDLER event-ref COMMA handler-ref SEMICOLON
remove-handler := REMOVE-HANDLER event-ref COMMA handler-ref SEMICOLON

event-ref      := member-access            // Объект.Событие
                | index-access             // Объект["Событие"]

handler-ref    := IDENTIFIER               // метод текущего модуля
                | member-access            // Объект.Метод
                | index-access             // Объект["Метод"]

member-access  := expression DOT IDENTIFIER
index-access   := expression LBRACKET expression RBRACKET
```

Ключевые слова (регистронезависимо):

| Русское | Английское |
|---|---|
| `ДобавитьОбработчик` | `AddHandler` |
| `УдалитьОбработчик` | `RemoveHandler` |

`event-ref` и `handler-ref` — **не произвольные выражения**: это структурные формы
«доступ к свойству» и «доступ по индексу». Выражения, не подходящие под форму, — ошибка
разбора.

## 2. Разбор: диагностика

| Ситуация | Сообщение | Позиция |
|---|---|---|
| После оператора не `member-access` и не `index-access` (источник) | `Ожидается имя события` | текущий токен |
| Обработчик не `Identifier`, не `member-access` и не `index-access` | `Ожидается имя обработчика события` | текущий токен |
| Нет `,` между источником и обработчиком | `Ошибка разбора: ожидается ','` | текущий токен |
| Нет `;` / конца блока | `Ошибка разбора: ожидается ';'` | текущий токен |

Сообщения и позиционирование — как в `LocalizedErrors.WrongEventName()` /
`WrongHandlerName()` и общем механизме ошибок парсера.

## 3. Семантика операций

| Операция | Наблюдаемое поведение |
|---|---|
| `ДобавитьОбработчик Источник.Событие, Обработчик` | Подписка на событие `Событие` объекта `Источник`; обработчик — метод `Обработчик` текущего объекта |
| `ДобавитьОбработчик Источник["Имя" + "События"], Обработчик` | Имя события вычисляется в момент подписки |
| `ДобавитьОбработчик Источник.Событие, ЭтотОбъект.Метод` | Обработчик — экспортный метод текущего объекта |
| `ДобавитьОбработчик Источник.Событие, Другой.Метод` | Обработчик — экспортный метод другого объекта |
| `УдалитьОбработчик …` | Снимает ровно подходящую подписку; отсутствие — не ошибка |
| Повторная подписка той же пары | Игнорируется (один вызов на событие) |
| `ВызватьСобытие(Имя)` | Вызывает обработчики без параметров; без подписчиков — no-op |
| `ВызватьСобытие(Имя, Массив)` | Передаёт элементы массива позиционными аргументами обработчику |
| `ВызватьСобытие` внутри метода загруженного сценария | Событие объявляется на объекте этого сценария, а не на вызвавшем модуле |
| Исключение в обработчике | Прерывает вызов остальных обработчиков и уходит коду, объявившему событие |
| `ЭтотОбъект` | Объект текущего модуля; методы — только экспортные |

## 4. Ошибки времени выполнения

| Ситуация | Ожидание |
|---|---|
| Подписка на неэкспортный метод через объект | `Метод объекта не обнаружен (<имя>)` |
| Обработчик-объект не является `BslObject` | ошибка типа значения |
| Источник события не является `BslObject` | ошибка типа значения |
| Имя метода при вызове не найдено у объекта | `Метод объекта не обнаружен (<имя>)` |

Текст «Метод объекта не обнаружен» — часть контракта: на него опирается эталонный тест
`ТестДолжен_ПроверитьЧтоПодпискаПоОбъектуВидитТолькоЭкспорт`.

## 5. Примеры

```bsl
// Объект-источник из другого модуля (аналог класса ТестСобытий в events.os)
Источник = ЗагрузитьСценарийИзСтроки(
  "Процедура СгенерироватьСобытие(Имя, Параметры) Экспорт
     ВызватьСобытие(Имя, Параметры);
   КонецПроцедуры");

Параметры = Новый Массив;
Параметры.Добавить("П1");
Параметры.Добавить("П2");

ДобавитьОбработчик Источник.МоеСобытие, ЭтотОбъект.ОбработчикСобытия;
Источник.СгенерироватьСобытие("МоеСобытие", Параметры);   // обработчик вызван с "П1", "П2"

УдалитьОбработчик Источник.МоеСобытие, ЭтотОбъект.ОбработчикСобытия;
Источник.СгенерироватьСобытие("МоеСобытие", Параметры);   // обработчик не вызван
```

Английские имена:

```bsl
AddHandler Source.MyEvent, ThisObject.EventHandler;
Source["My" + "Event"] ...
RaiseEvent("MyEvent", Params);
```

## 6. Что НЕ входит в контракт

- Объявление событий (`Событие` как элемент метаданных) — в BSL событие не декларируется;
  подписка привязывается к строковому имени.
- Асинхронная/фоновая доставка, приоритеты обработчиков.
- `ПодключитьСценарий` и `Новый <Тип-из-файла>` — T39.
- DOM-события браузера (`НаСобытие`, `data-os-*`) — Фаза 7, отдельная поверхность.
