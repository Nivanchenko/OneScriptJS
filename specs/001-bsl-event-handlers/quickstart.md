# Quickstart: проверка событий BSL

**Date**: 2026-11-11 | **Plan**: [plan.md](plan.md) | **Contract**: [contracts/event-handler-contract.md](contracts/event-handler-contract.md)

Назначение: воспроизводимые команды и сценарии, доказывающие, что фича работает
end-to-end. Реализационные детали — в `tasks.md` (Phase 2), здесь только запуск и
ожидаемые результаты.

## Предпосылки

- Node.js >= 20 (в DSH: системный node из nvm, см. `AGENTS.md` §6).
- Установленные зависимости: `pnpm install`.
- Эталон для сверки: `reference/OneScript/` (клон апстрима, в `.gitignore`).

## 1. Базовая проверка (до изменений)

```bash
pnpm typecheck
pnpm test
node scripts/run-reference-tests.mjs
```

Ожидаемо на текущей базе: typecheck без ошибок; 300 тестов зелёные; корпус 18/66;
`events.os` падает на разборе с `ожидается ';'` (строка 57).

## 2. Приёмочные сценарии фичи (Vitest)

```bash
pnpm test tests/events.test.ts
```

Ожидаемо: все сценарии зелёные. Каждый воспроизводит пункт `events.os` либо краевой
случай из спецификации:

| # | Сценарий | Что проверяет |

| 1 | Подписка и объявление события с параметрами | FR-001, FR-005; обработчик вызван один раз с `"П1"`, `"П2"` |

| 3 | Локальный метод модуля как обработчик | FR-004; метод, а не переменная с тем же именем |

## 3. Браузерная приёмка

```bash
pnpm test tests/browser-events.test.ts
pnpm build:browser
```

Ожидаемо: happy-dom исполняет `<one-script>` с `ДобавитьОбработчик` и объявлением
события, вывод доходит до `console.log`; `dist/onescript.js` собирается.

Ручная проверка (опционально):

```bash
pnpm build:browser && pnpm dev
# открыть http://localhost:5173/examples/hello.html — страница работает как раньше
```

## 4. Регрессия

```bash

```

Ожидаемо: typecheck чистый; все тесты зелёные (300 + новые); корпус — **не хуже 18/66**,

```bash

```

Ожидаемо: собираются `dist/onescript.js`, `dist/node/*`, `dist/cli.mjs`, типы без ошибок.

## Минимальный ручной сценарий (Node)

```bash
cat > /tmp/events.os <<'OS'
Перем Вызовов;

Функция Считать(А)
  Вызовов = Вызовов + 1;
  Возврат А;
КонецФункции

Вызовов = 0;
Источник = ЗагрузитьСценарийИзСтроки("Процедура Сгенерировать(Имя) Экспорт
|  ВызватьСобытие(Имя);
|КонецПроцедуры");
ДобавитьОбработчик Источник.Событие, Считать;
Источник.Сгенерировать("Событие");
Сообщить(Вызовов);
OS
node dist/cli.mjs /tmp/events.os
```

Ожидаемый вывод: `1`.
