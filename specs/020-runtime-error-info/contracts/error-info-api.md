# Contract: BSL-поверхность `ИнформацияОбОшибке` и `КадрСтекаВызовов`

**Feature**: `specs/020-runtime-error-info` | **Тип**: публичный BSL-API

## Пример использования

```bsl
Попытка
  Результат = 1 / 0;                 // строка 2
Исключение
  Ош = ИнформацияОбОшибке();
  Сообщить(Ош.Описание);             // «Деление на ноль» — как раньше
  Сообщить(Ош.ИмяМодуля);            // «script.osjs»
  Сообщить(Ош.НомерСтроки);          // 2
  Сообщить(Ош.ИсходнаяСтрока);       // «  Результат = 1 / 0;»
  Для Каждого Кадр Из Ош.ПолучитьСтекВызовов() Цикл
    Сообщить(Кадр.Метод + " (" + Кадр.ИмяМодуля + ":" + Кадр.НомерСтроки + ")");
  КонецЦикла;
  Сообщить(Ош.ПодробноеОписаниеОшибки());  // описание + стек
КонецПопытки;
```

## `ИнформацияОбОшибке` / `ErrorInfo`

Свойства (только чтение; неизвестное свойство — исключение, как сейчас):

| RU | EN | Тип | Значение |
|---|---|---|---|
| `Описание` | `Description` | Строка | Текст ошибки; **не меняется** относительно текущего поведения |
| `ИмяМодуля` | `ModuleName` | Строка | Идентификатор источника (см. data-model.md); `""` для пустой ошибки |
| `НомерСтроки` | `LineNumber` | Число | 1-based строка возникновения; `0` для пустой ошибки |
| `ИсходнаяСтрока` | `SourceLine` | Строка | Текст исходной строки; `""`, если недоступен |
| `Причина` | `Cause` | Null | Всегда `Null` |

Методы:

| RU | EN | Параметры | Возвращает |
|---|---|---|---|
| `ПодробноеОписаниеОшибки` | `DetailErrorDescription`, `DetailedDescription` | — | Строка: описание + стек |
| `ПолучитьСтекВызовов` | `GetStackTrace` | — | `КоллекцияКадровСтекаВызовов` |

Совместимость:

- `ПодробноеОписаниеОшибки` ранее было **свойством**, возвращавшим `Описание`. Свойство
  сохраняется (тот же результат, что у метода), метод добавляется как 1С-совместимый способ.
- `ИнформацияОбОшибке()` вне блока `Исключение` — пустая ошибка: `Описание` = `""`,
  `НомерСтроки` = 0, `ИмяМодуля`/`ИсходнаяСтрока` = `""`, `ПолучитьСтекВызовов()` — пустой
  `КоллекцияКадровСтекаВызовов`; `ПодробноеОписаниеОшибки` = `""`.
- Повторный бросок объекта (`ВызватьИсключение ИнформацияОбОшибке()`) сохраняет исходные
  позицию и стек.

## `КоллекцияКадровСтекаВызовов` / `CallStackFramesCollection`

Возврат `ПолучитьСтекВызовов()`. Члены:

| RU | EN | Вид | Тип |
|---|---|---|---|
| `Количество` | `Count` | метод | Число |
| `[i]` | — | индексация (0-based) | `КадрСтекаВызовов` |
| `Для Каждого` | — | итерация | `КадрСтекаВызовов` |

- Порядок: изнутри наружу (первый элемент — кадр возникновения).
- `ТипЗнч(коллекция)` = `КоллекцияКадровСтекаВызовов`;
  `Тип("CallStackFramesCollection")` канонизируется в него же.
- Выход за диапазон — исключение; запись/неизвестный метод — исключение.

## `КадрСтекаВызовов` / `CallStackFrame`

Свойства (только чтение):

| RU | EN | Тип | Значение |
|---|---|---|---|
| `Метод` | `Method` | Строка | Имя метода; маркеры `<модуль>`, `<Выполнить>`, `<Вычислить>`, `<обработчик>` |
| `ИмяМодуля` | `ModuleName` | Строка | Идентификатор источника кадра |
| `НомерСтроки` | `LineNumber` | Число | 1-based строка кадра на момент ошибки |

- Порядок массива: изнутри наружу (первый элемент — кадр возникновения).
- `ТипЗнч(кадр)` = `КадрСтекаВызовов`; `Тип("CallStackFrame")` канонизируется в него же.
- Индексация и запись свойств недоступны.

## Формат `ПодробноеОписаниеОшибки`

```
<Описание>
Стек вызовов:
  <Метод> (<ИмяМодуля>:<НомерСтроки>)
  ...
```

- Для пустой ошибки — `""`.
- Формат фиксируется тестом; изменение — ломающее для тестов и документации.

## Ошибки

- Неизвестное свойство — исключение с текстом в стиле текущего
  `Свойство '<имя>' не найдено у типа ИнформацияОбОшибке`.
- Вызов метода с аргументами — исключение (нет параметров).
- Запись в любое свойство — исключение.
