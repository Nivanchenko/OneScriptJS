# Quickstart: проверка позиции, модуля и стека в ошибках

**Feature**: `specs/020-runtime-error-info`

## Предварительно

```bash
pnpm install          # если зависимости ещё не установлены
pnpm typecheck
pnpm test             # весь набор должен быть зелёным
```

## 1. CLI: ошибка с файлом, строкой и стеком

```bash
pnpm build:cli
cat > /tmp/bad.osjs <<'EOF'
Процедура Внутренняя()
  Результат = 1 / 0;          // строка 2
КонецПроцедуры

Внутренняя();                 // строка 5
EOF
node dist/cli.mjs /tmp/bad.osjs; echo "exit=$?"
```

Ожидаемо (stderr):

```
/tmp/bad.osjs:2: Деление на ноль
Стек вызовов:
  Внутренняя (/tmp/bad.osjs:2)
  <модуль> (/tmp/bad.osjs:5)
```

и `exit=1`.

## 2. BSL-код читает сведения об ошибке

```bash
cat > /tmp/info.osjs <<'EOF'
Процедура Сломать()
  А = 1 / 0;
КонецПроцедуры

Попытка
  Сломать();
Исключение
  Ош = ИнформацияОбОшибке();
  Сообщить(Ош.Описание);
  Сообщить(Ош.ИмяМодуля);
  Сообщить(Ош.НомерСтроки);
  Сообщить(Ош.ИсходнаяСтрока);
  Для Каждого Кадр Из Ош.ПолучитьСтекВызовов() Цикл
    Сообщить(Кадр.Метод + ":" + Кадр.НомерСтроки);
  КонецЦикла;
  Сообщить(Ош.ПодробноеОписаниеОшибки());
КонецПопытки;
EOF
node dist/cli.mjs /tmp/info.osjs
```

Ожидаемо: `Описание` = `Деление на ноль`, `ИмяМодуля` = `/tmp/info.osjs`,
`НомерСтроки` = `2`, `ИсходнаяСтрока` = `  А = 1 / 0;`, стек — `Сломать:2`, `<модуль>:6`,
подробное описание — описание + `Стек вызовов:`.

## 3. Перевыброс сохраняет позицию

```bash
cat > /tmp/rethrow.osjs <<'EOF'
Попытка
  Попытка
    А = 1 / 0;                 // строка 3
  Исключение
    ВызватьИсключение;         // строка 5
  КонецПопытки;
Исключение
  Сообщить(ИнформацияОбОшибке().НомерСтроки);   // ожидаем 3
КонецПопытки;
EOF
node dist/cli.mjs /tmp/rethrow.osjs
```

## 4. Браузер

```bash
pnpm build:browser
pnpm dev
```

Открыть `examples/errors.html` (добавляется фичей) — страница ловит ошибку в
`Попытка/Исключение` и печатает свойства; в DevTools Console видна ошибка блока с
`http://localhost:5173/examples/errors.html#blockN:<строка>` и стеком.

Автоматическая проверка браузерного формата — `tests/browser-errors.test.ts` (happy-dom),
запускается в общем `pnpm test`.

## 5. Полная проверка перед «готово»

```bash
pnpm typecheck && pnpm test
pnpm build
pnpm check:docs
pnpm typecheck:vscode   # если затронут LSP/каталог
```
