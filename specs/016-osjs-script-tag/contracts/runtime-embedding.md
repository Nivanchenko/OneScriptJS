# Contract: runtime-встраивание `<script type="text/osjs">`

## DOM

- **Наш блок** — `script` с `type` = `text/osjs` (сравнение ASCII case-insensitive).
  Другие `type` (включая `text/javascript`, `module`, пустой) не исполняются.
- Блоки собираются в **порядке документа** (`document.querySelectorAll('script[type]')`
  с фильтром) на момент старта.
- `<one-script>` **не поддерживается**: кастомный элемент не регистрируется, CSS
  `one-script { display: none }` не инжектируется, содержимое не исполняется.
- `src` **игнорируется** (v1); динамически добавленные блоки **не исполняются** (v1;
  динамика — через JS-API `run`/`runScript`).
- Содержимое — HTML raw text: `<`, `>`, `&` literal; `</script>` завершает блок.

## Исполнение

- **Момент старта**: если `document.readyState !== 'loading'` — сразу при инициализации
  модуля; иначе — один раз на `DOMContentLoaded`. Повторный запуск запрещён.
- **Порядок**: последовательный (`for … await executeBlock`), ошибка загрузки модулей
  следующего блока не блокирует.
- **Контекст**: на каждый блок — свежий `createBrowserGlobalContext()`; импорты
  `#Использовать` разрешаются относительно `document.baseURI`.
- **Ошибки**: исключение/ошибка импорта ловится внутри блока → `console.error`; остальные
  блоки исполняются; наружу ничего не пробрасывается.
- **Контексты `data-os-*`**: `registerScriptContext(el.id || null, ctx)`; первый блок без
  `id` — контекст по умолчанию; дубликат `id` — «последний побеждает»; декларативные
  обработчики привязываются после исполнения блока (`scheduleDeclarativeBinding`).

## Безопасность и совместимость

- Data block не исполняется браузером; новых поверхностей исполнения не появляется.
- CSP: неисполняемые inline-script не должны блокироваться `script-src`; при ином поведении
  — задокументировать требование (nonce/hash), не ослабляя политику.
- Ядро (`src/runtime`, `src/lexer`, `src/parser`, `src/stdlib`), Node/CLI и `.osjs`-формат
  не меняются.

## Проверяемость (acceptance anchors)

1. `document.body.innerHTML = '<script type="text/osjs">Сообщить("ok");</script>'` →
   `console.log("ok")`, блок не в тексте страницы.
2. Два блока → порядок вывода = порядок документа; исключение в первом не мешает второму.
3. `Если А<Б Тогда` без пробелов; `"Tom & Jerry"`, `"</div>"` — значения без искажений.
4. `<script type="text/osjs" id="app">` + `data-os-click`/`data-os-script="app"` →
   обработчик в контексте блока.
5. `<one-script>` → код не исполняется, элемент не скрывается нашим CSS.
6. `script[type="text/OSJS"]` (регистр) → исполняется.
7. Код с `</script>` в строке → runtime-ошибка разбора в `console.error` (не тихий успех);
   диагностика Error — в embedded-слое 015 (контракт `OSJS4001`).
