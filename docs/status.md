# OneScriptJS — статус (компактная сводка)

Движок OneScript (язык 1С/BSL), переписанный на TypeScript. Работает в Node и браузере.
Оригинал (эталон) — `reference/OneScript/` (C#), не коммитится.

## Состояние
- Весь план **T1–T30** выполнен + добивки (`Формат`, системные перечисления).
- `pnpm typecheck` ✓, `pnpm test` ✓ — **186 тестов** (28 файлов Vitest).
- Ветка `feat/rewright`.

## Архитектура (слои)
`src/lexer` (токены) → `src/parser` (AST + препроцессор `#`) → `src/runtime`
(`values`, `scope`+`Ref`, `context`, `interpreter` tree-walking, `enum`, `object`,
`type`, `error-info`, `runner`) → `src/stdlib` (global-context, collections, strings,
math, bitwise, json, types, enums, format) → `src/browser/onescript.ts` (`<one-script>`)
и `src/node/` (cli, context, files) → `src/testing` (xUnit-раннер).

Сборка: `dist/onescript.js` (браузер, IIFE), `dist/node/index.{js,cjs,d.ts}` (библиотека),
`dist/cli.mjs` (CLI).

## Что реализовано
- Язык: переменные, `если/иначеесли/иначе`, циклы (`Для`/`Пока`/`Для Каждого`,
  `Прервать`/`Продолжить`), процедуры/функции (`Знач`/по ссылке), исключения,
  `Перейти`/метки, аннотации, тернарный `?()`, `Новый`, препроцессор `#`.
- Значения/типы: числа, строки, булево, даты, `Null`/`Неопределено`, `Тип`/`ТипЗнч`,
  перечисления (`НаправлениеПоиска`, `СтатусСообщения`, `ХешФункция`, `ЦветКонсоли`,
  `КодировкаТекста`, `СпециальнаяПапка`, `ТипДиска`, `НаправлениеСортировки`,
  `СпособКодированияСтроки`) и `Символы`.
- Коллекции: `Массив` (многомерный), `Структура`, `Соответствие` (+ фиксированные).
- stdlib: `Сообщить` (со статусом), строковые, математические, поразрядные (uint32),
  JSON, `Формат` (число/дата), файловые (Node: `ЧтениеТекста`/`ЗаписьТекста`/`ОбъединитьПути`).
- Тестирование: xUnit-раннер `runTests` (`ЮнитТестирование` с `Проверить*`).

## Известные пробелы
- `asserts`-библиотека (`Ожидаем.Что(...).Равно(...)`), сеть/HTTP, процессы, COM,
  `ЗагрузитьСценарийИзСтроки`, XML, полный `Файл`-объект, `ТекущийСценарий`,
  `Формат`: `ЧГ` с кастомными размерами/`ДП`/`ДД`, локаль ru_RU (аппроксимация `\u00A0`).
