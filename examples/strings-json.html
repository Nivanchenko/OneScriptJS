Строки, JSON и Формат

Готовые функции стандартной библиотеки: шаблоны, разбор и сборка строк, числовые и датовые форматы, сериализация Структуры в JSON и обратно. Результат выводится в видимый <pre>.



  

  
    Перем Вывод;

    Процедура СтрокаОтчёта(Знач Текст)
      Вывод.Текст = Вывод.Текст + Текст + Символ(10);
    КонецПроцедуры

    Вывод = Документ.ПолучитьЭлемент("вывод");

    // СтрШаблон подставляет аргументы вместо %1, %2, …
    СтрокаОтчёта("1. СтрШаблон: " + СтрШаблон("Привет, %1! Сегодня %2.", "мир", "пятница"));

    // СтрРазделить/СтрСоединить — разбор строки и обратная сборка
    Части = СтрРазделить("яблоко, банан, груша", ", ");
    СтрокаОтчёта("2. СтрРазделить → " + Строка(Части.Количество()) + " части: " + СтрСоединить(Части, " | "));

    // СтрЗаменить меняет все вхождения подстроки
    СтрокаОтчёта("3. СтрЗаменить: " + СтрЗаменить("дорога домой", "дорога", "путь"));

    // Формат: ЧДЦ — знаков после запятой, ЧРД/ЧРГ — разделители, ЧГ=0 — без группировки
    ДатаОтчёта = Дата(2026, 11, 11, 15, 30, 0);
    СтрокаОтчёта("4. Формат числа: " + Формат(1234567.5, "ЧДЦ=2; ЧРД=','; ЧРГ=' '"));
    СтрокаОтчёта("   Формат даты: " + Формат(ДатаОтчёта, "ДФ='dd.MM.yyyy HH:mm'"));

    // JSON: Структура → строка и строка → Структура
    Данные = Новый Структура("имя, город, возраст", "Анна", "Москва", 30);
    JSON = ЗаписатьJSON(Данные);
    СтрокаОтчёта("5. ЗаписатьJSON: " + JSON);

    Прочитано = ПрочитатьJSON(JSON);
    СтрокаОтчёта("   ПрочитатьJSON: имя = " + Прочитано.имя + ", город = " + Прочитано.город +
      ", возраст = " + Строка(Прочитано.возраст));
